Suara karakter: pilihan dan batas aktivasi

Saat ini hanya sampel privat. Rekaman opsional sudah dipisahkan dari narasi video. Tidak ada provider dipilih, dihubungkan, didaftarkan, atau dipanggil. Tidak ada sampel dikirim keluar. “Sampel tersimpan” bukan suara otomatis yang sudah aktif.

Rekomendasi untuk DR

Pertahankan fase penyimpanan ini. Jika DR kelak menyetujui percobaan cloning berbayar, ElevenLabs Instant Voice Cloning paling langsung untuk pilot kecil berbahasa Indonesia; MiniMax Rapid Voice Cloning layak menjadi pembanding biaya. Ini rekomendasi kandidat, bukan pilihan/aktivasi otomatis dan bukan klaim kualitas suara sudah terbukti.

OpenVoice berlisensi lebih longgar dan bisa di-host sendiri, tetapi Indonesia membutuhkan base TTS yang cocok dan rekayasa tambahan. XTTS-v2 tidak direkomendasikan untuk pemasaran Solid Gold: bahasa Indonesia tidak tercantum dan bobot model berlisensi nonkomersial.

Retensi, pelatihan, dan penghapusan

  • Self-host OpenVoice / XTTS: bila seluruh inference benar-benar lokal, sampel tidak perlu dikirim ke vendor model. Retensi byte, embedding, cache, output, log dan backup ditentukan operator. Menghapus WAV saja tidak otomatis menghapus semua embedding/model/backup. Zero-shot tidak sama dengan melatih ulang bobot global; fine-tuning terpisah memerlukan evaluasi privasi tambahan. “Lokal” bukan jaminan tanpa telemetry/dependensi jaringan: audit seluruh pipeline sebelum pilot.
  • ElevenLabs: retensi default aktif. Zero Retention Mode khusus pelanggan Enterprise yang memenuhi syarat dan endpoint tertentu; IVC/PVC tidak memenuhi syarat ZRM karena clone harus disimpan. Opt-out “Improve the models for everyone” melindungi data baru setelah dimatikan; jangan dianggap menarik kembali pelatihan data lama. Enterprise default tidak melatih pada data kecuali yang diperlukan untuk layanan. API delete voice tersedia, tetapi bukan bukti penghapusan seketika seluruh backup/log. Panduan ZRM menyebut backup retained database items hingga 30 hari setelah deletion, dan log debug/moderasi dapat bertahan. Masa retensi spesifik semua turunan voice perlu persetujuan kontraktual. Clone tidak dapat diekspor sebagai model mandiri.
  • MiniMax: dokumentasi clone menyebut voice yang belum dipakai dalam 7 hari dihapus. Ini bukan jaminan seluruh sampel, clone yang telah dipakai, output dan backup dihapus setelah 7 hari. API delete voice ada. Terms mengizinkan penggunaan input/generated content untuk menyediakan, memelihara, mengembangkan, dan meningkatkan layanan. Jaminan no-training/opt-out dan tenggat penghapusan semua turunan suara/backup belum terverifikasi; Privacy Policy memakai retensi selama perlu/diizinkan hukum. Perlu klarifikasi tertulis sebelum memakai suara pegawai.

Contoh biaya, bukan estimasi tagihan final

Untuk naskah 250 karakter: tarif variabel ElevenLabs Flash/Turbo sekitar US$0,01, Multilingual v2 US$0,02; MiniMax Turbo US$0,015, HD US$0,025. Contoh 300 naskah demikian: US$3 / US$6 / US$4,50 / US$7,50. Ini hanya perkalian tarif karakter—bukan total bulanan, belum minimum paket, alokasi yang sudah termasuk, cloning (misalnya MiniMax US$1,50/voice), preview, retry, pajak, kurs, transfer, storage aplikasi dan komputasi video. Jangan menambah ulang usage yang sudah termasuk paket saat menyusun anggaran.

WAV tersimpan lokal maksimal sekitar 1,92 MB per 60 detik (mono 16 kHz PCM16), plus staging sementara hingga 10 MiB. Total biaya storage = GB-bulan × tarif storage, operasi dan transfer. Total self-host = waktu CPU/GPU aktif + waktu idle yang ditagih + storage model/sampel/output + transfer + operasional. Angka tarif dan waktu riil belum diukur; tanpa biaya API tidak berarti gratis.

Keputusan sebelum aktivasi

  1. Pilih kandidat/model dan batas biaya pilot; pastikan hak komersial serta tarif cloning, sintesis, preview, penyimpanan dan retry yang berlaku saat aktivasi.
  2. Setujui transfer suara/naskah ke provider tertentu, tujuan penggunaan, retensi, pelatihan/opt-out, lokasi data, hak pencabutan dan bukti penghapusan. Checkbox penyimpanan sampel sekarang bukan izin eksternal.
  3. Tentukan kualitas/durasi master baru. Sampel sekarang 5–60 detik, dinormalisasi mono 16 kHz, belum tentu cukup bagi MiniMax, IVC optimal atau PVC.
  4. Baru setelah persetujuan terpisah: hubungkan integrasi aman, bangun adapter dan ledger permintaan, kunci versi provider per job, batas anggaran, dan uji kalimat Indonesia serta penghapusan nyata. Timeout eksternal tidak boleh langsung dikirim ulang tanpa rekonsiliasi.
